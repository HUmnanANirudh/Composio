          How the agent works

          A Python pipeline gathers sources and checks every answer; Composio supplies the catalog cross-check and Exa search. Square markers are human steps.

          deterministic

          Composio catalog

          Match each app to Composio's public 1,841-toolkit catalog: existing toolkit, tool count, auth schemes, vendor MCP proxy.

          crawler + Composio → Exa

          Discover sources

          Crawl the official docs host and its llms.txt, follow auth, pricing and MCP links, then search with EXA_SEARCH through a Composio session.

          Claude, in-session

          Extract, pass 1

          Read each app’s source pack and fill a rubric of fixed enums. Every field cites a source and a verbatim quote. The Composio catalog is withheld so it stays an independent check.

          deterministic + Exa re-research

          Verify, three loops

          Grounding: is the quote on the page? Rules: consistency and Composio cross-checks. Re-research: new sources for flagged fields only, read again, then grounding and rules re-run.

          human

          Answer key

          20 apps drawn at random (2 per category, fixed seed) before any run, checked by hand against official docs.

          deterministic

          Score + patterns

          Pass 1 vs final, field by field, against the key. Patterns are plain counts over the final records.

          Where a human was needed

          • Catalog matching. 20 ambiguous app-to-toolkit matches were pinned by hand.
          • Search key. Composio’s built-in search is retired, so a human connected an Exa key.
          • Answer key. 20 apps checked by hand against vendor docs.
          • Reading step. LLM free tiers (Groq, Gemini) ran out, so Claude read the source packs in-session. The pipeline still gathered every source and re-checked every quote.
          • Reviewing misses. Every miss got a verdict (agent wrong, key wrong or ambiguous) in data/audit.json.

          Run it yourself

          On GitHub: Actions → Run research agent, then type an app name. Or locally:

          uv sync && cp .env.example .env   # COMPOSIO, EXA, GEMINI keys
uv run research connect-search    # one-time: Exa → Composio
uv run research run --apps Attio  # research one app
uv run research evaluate          # score against the answer key

          Where it fell short

          • “Paygent Connect” could not be identified from its sources.
          • JavaScript-rendered docs return almost no text to a plain fetch.
          • Access is the hardest field: pricing pages rarely say if the API is on the free plan.
          • The answer key covers 20 of 100 apps.
