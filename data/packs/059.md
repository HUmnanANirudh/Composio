The API host is https://api.waterfall.io. Data endpoints use /v1/; Account Reporter V2 uses /v2/account. Use the path shown on each reference page.
Best practices
- Store keys in server-side environment variables. Keep them out of browser code and public repositories.
- Rotate keys periodically.
- Use dedicated sub-keys to manage access and usage for separate teams or workflows. Creating and managing sub-keys requires a master API key.
Missing keys return
401. Invalid keys return 403; this status can also indicate that a feature or permission is unavailable to the key. Inspect the error code using the Errors guide.

About Waterfall
What is Waterfall used for?
Waterfall.io is a B2B data API for go-to-market workflows. Use Waterfall to find people at target accounts, enrich contact and company records, match emails to business profiles, find phone numbers, verify email addresses, and check job changes.
Who is Waterfall for?
Waterfall serves growth, revenue, and go-to-market teams. GTM engineers build prospecting workflows, revenue operations teams fill gaps in CRM records, and product-led growth teams add business context to signups. Developers can also add contact and company data to GTM tools, recruitment platforms, CRMs, marketing software, and other products.
Who are Waterfall.io’s customers?
Waterfall.io’s current and past customers include Ramp, Gorgias, Zapier, Lightfield, JOIN, awork, Coverflex, Netic, 360Learning, Rippling, and ClickUp.

How the API works
Send requests tohttps://api.waterfall.io with your API key in the x-api-key header. Authentication covers access and key management.
Prospector and the contact, phone, and company enrichment APIs return a job_id. Use the matching Finder to retrieve the result, or provide a webhook_url to receive it. Search and verification APIs return results in the same request. The API selection guide lists the response pattern and availability for each capability.
Every reference page shows the supported inputs and outputs. Use Usage Tracking to read returned costs, and Account Reporting for usage across a date range.

[S8] https://docs.waterfall.io/v1/introduction (official)
The Waterfall API is available at
https://api.waterfall.io. Send your API key in the x-api-key header. See Authentication.
Endpoints
Choose an API based on what you already know and what you want to find. The guidance below separates search, enrichment, verification, and employment checks.
Find people and contact details
Search Contact or Prospector? Use Search Contact when you need profile search and structured filters. Use Prospector when you have a target account and want to find people and contact details by title. To enrich someone found through Search Contact, pass their LinkedIn identifier to Contact Enrichment. See account prospecting for the workflow.
Find and enrich companies
For existing CRM records, use CRM enrichment. For website traffic, start with website company identification.
Check a contact’s employment
Job Change checks a contact’s company information and returns a status with an available profile snapshot. Start with a supported company-and-contact identifier combination or a professional email. If you need recurring checks, your workflow schedules the requests and compares the results. See job changes.
When do results arrive?
For async APIs, the launcher returns ajob_id. Retrieve the result with the matching Finder or receive it through webhook_url.
For sync data APIs, read the result in the POST response. Where a Finder exists, use it to retrieve the saved result later. Email Verification has no Finder.
The job’s status describes processing. Inspect the returned data to decide whether it is useful for your task. A SUCCEEDED job does not promise that every requested field was found.
Search Company and Company Titles are Preview APIs. Their behavior may change. Check the relevant reference before building a critical workflow around a Preview API.
Manage your integration
- API Keys Management: create and manage keys for your workflows.
- Usage Tracking: inspect a job’s returned cost and balance snapshot.
- Account Reporting: read usage across a date range.
- Webhook Verification: verify the origin and integrity of signed deliveries.
