This is the new v3 MCP server. The previous v2+ MCP server is deprecated and lives at dataforseo/mcp-server-typescript-deprecated.
MCP server and CLI for LLM agents to browse DataForSEO API documentation and make authenticated API requests. By default the binary starts an MCP server on stdio; CLI commands are an optional second mode.
Start the MCP server on stdio (default mode; set DATAFORSEO_LOGIN / DATAFORSEO_PASSWORD):
npx dataforseo-mcp-server@latest
HTTP transport (port 3000; override with PORT):
npx dataforseo-mcp-server@latest --mode http
OAuth 2.0 (default for HTTP MCP): works out of the box. MCP clients discover the DataForSEO authorization server via Protected Resource metadata and send Authorization: Bearer tokens.
Fallback: API login/password via environment variables (HTTP Basic). Required for CLI and stdio MCP; on HTTP it is used when no Authorization header is present.

# bash / macOS / Linux
export DATAFORSEO_LOGIN="your_api_login"
export DATAFORSEO_PASSWORD="your_api_password"# PowerShell
$env:DATAFORSEO_LOGIN="your_api_login"
$env:DATAFORSEO_PASSWORD="your_api_password"REM CMD
set DATAFORSEO_LOGIN=your_api_login
set DATAFORSEO_PASSWORD=your_api_password
DATAFORSEO_USERNAME is accepted as an alias for DATAFORSEO_LOGIN. Get API keys at https://app.dataforseo.com/api-access.
The same tool implementations power both the MCP server and the CLI. One binary serves both modes; MCP is the default.
How the binary chooses a mode:
- MCP stdio — default when no CLI command is passed
- MCP HTTP — pass --mode http (Streamable HTTP on port 3000; override with PORT)
- CLI — when the first command is docs or request, or when --cli / --help / --version is passed

Starting today, July 1, 2026, we’re introducing a pricing update necessary to support the continued performance, reliability and quality of DataForSEO APIs. We’re applying adjusted rates across selected APIs and moving all endpoints to a pay-as-you-go model by cancelling monthly commitments.
We want to share this update with full transparency and sincere appreciation for your continued trust.
What’s changed
From today, updated rates apply across eight APIs. The standard adjustment is approximately 20%, with several endpoint-specific exceptions listed below.
- Backlinks API: +20% for all endpoints
- Business Data API: +20% for Business Listings Search and Categories Aggregation endpoints, +7% per request for Google Hotel Searches Task POST
- Content Analysis API: +20% for most endpoints, +18.2% for Rating Distribution
- DataForSEO Labs API: +20% for all endpoints
- Domain Analytics API: +20% for all endpoints
- Keywords Data API: +20% for most endpoints, +22% for Google Trends Explore
- On-Page API: +20% for most endpoints, +18% for Lighthouse Task POST and Live
- Merchant API: +50% for Amazon Products and Sellers Task POST
Monthly commitment removal
The $100 monthly commitment for the Backlinks API and LLM Mentions API access is now removed. This means you no longer need to meet a monthly minimum payment requirement to use these APIs. Access to both APIs is now available under the same pay-as-you-go model used across all DataForSEO APIs.
Context behind the change
We understand that pricing is an important part of your decision-making, planning and budgeting, and any update like this deserves clear context. That is why we want to be upfront about why we’re making this change.
We’ve kept pricing stable for years while infrastructure and processing costs have continued to rise. This pricing adjustment allows us to maintain the speed, reliability, and data quality you count on every day.
Visit your account dashboard to review up-to-date pricing details for specific APIs and endpoints you use.
