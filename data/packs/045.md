- [Magento REST or SOAP Web APIs]({{ page.baseurl }}/get-started/bk-get-started-api.html)

Access to Adobe Commerce Sandbox
Adobe wants to support the Magento community and will provide an Adobe Commerce sandbox to build and test your integration. To qualify for a sandbox you must meet the below criteria:
- Join the Adobe Technology Partner Program partner program by registering here.
- Be in good standing in the Commerce Marketplace.
- Within six months of getting a sandbox have an extension submitted and approved in the Commerce Marketplace.
If a partner does not have an extension in the Commerce Marketplace at six months, we will remove the sandbox access, and it will not be restored. After that, sandbox access is a Silver partnership benefit.
If your company has lost sandbox access and you believe you qualify for a sandbox under the conditions outlined above, please request access by filing a ticket here.
To get sandbox access, please submit a support ticket. Detailed instructions are here. Once you get your sandbox, the below articles might be helpful:
- To refresh your cloud sandbox you can see the Reset Environment on Cloud article.
- Check out our Deployment Troubleshooter article if you have a stuck deployment.
- And then all topics are covered in the Commerce Support Help Center.

- Build your integration and then test it using the Cloud Docker Environment.

Integrations
Defining an integration in the Commerce Admin establishes the location of OAuth credentials and redirect URL for third-party integrations, and identifies the available API resources that are needed for the integration. For more detailed information about the integration registration process, see OAuth-based authentication in the Commerce developer documentation.
{width="700" modal="regular"}
Onboarding workflow
- Authorize the integration - Go to the System > Extensions > Integrations page, find the relevant integration, and authorize.
- Verify and establish login - When prompted, accept the access requested. If redirected to a third-party, log in to the system, or create an account. After a successful login, you return to the integration page.
- Receive confirmation of authorized integration - The system sends notification that the integration has been authorized successfully. After setting up an integration and receiving the credentials, it is no longer necessary to make calls to access or request tokens.
