Create an application for the API
In this article:
To create an application for general use, you'll need to build a Redirect URI handler to generate access tokens for each of your users. However, if you only want to use the API on your own Gumroad account, you can manually generate an access token, which is a simpler process.
For just your account
If you're writing some custom code you need to run with your Gumroad account, all you need is an access token. Your access token is used in the request header of every request to the API and should be kept secret, like a password.
Generating an access token
First, sign in to your Gumroad account. Then, go to advanced settings. Here, you'll see a form to create a new application.
Provide the following information and click "Create application":
- Application icon: A small thumbnail image to identify your application.
- Application name: A name for your application
- Redirect URI: While this is very important when making a general-purpose application, when you just want an access token to use the API with your own account, simply enter localhost (http://127.0.0.1) in this field, as its value is not meaningful.

Connecting AI assistants to your Gumroad store
In this article:
What the Gumroad connector is
Gumroad runs a server that speaks MCP (Model Context Protocol), so an AI assistant that supports MCP can work with your store from your chat. You connect your Gumroad account once, sign in through Gumroad, and then you can ask the assistant things like "show my recent sales" or "draft a product called Photo Pack for $12".
Nothing about your store changes. Products, customers, sales, and payouts all stay in Gumroad, and customers still pay through Gumroad checkout. The connector is a way to read your store's data and make a few changes from chat instead of from your dashboard.

[S5] https://gumroad.com/llms.txt (official)
# Gumroad

> Gumroad is an e-commerce marketplace where independent creators sell digital products — ebooks, courses, music, software, design assets, memberships, and more — directly to their audiences.

Every product is sold by an individual creator. Each creator has a storefront on their own subdomain, and every product has a canonical short URL. Discover is the marketplace-wide browse and search surface, organized as a taxonomy of categories with nested subcategories (for example 3D, Design, Education, Software Development), each addressable at its own path.

## URL patterns

- [Product pages](https://gumroad.com/help/article/136-find-your-products-url): `https://gumroad.com/l/{permalink}` — canonical page for a single product
- [Creator storefronts](https://gumroad.com/): `https://{username}.gumroad.com` — a creator's profile and product listing
- [Discover](https://gumroad.com/discover): marketplace browse and search; categories and subcategories are paths like `https://gumroad.com/{category}` and `https://gumroad.com/{category}/{subcategory}`
- [Wishlists](https://gumroad.com/help/article/343-wishlists): `https://{username}.gumroad.com/wishlists/{slug}` — public, shareable product lists curated by users, served from the creator's storefront subdomain

## Pricing

- [Pricing](https://gumroad.com/pricing): no monthly fee; Gumroad charges 10% + $0.50 per transaction on sales made through a creator's own profile or direct links, and 30% per transaction when a new customer finds the product through Discover. Gumroad is the merchant of record and handles sales tax collection and remittance worldwide.

## API

- [API documentation](https://gumroad.com/api): public REST API for products, sales, subscribers, and licenses
- [Muse](https://gumroad.com/muse) and [Claude](https://gumroad.com/claude) connectors: OAuth + MCP so an agent can list sales, draft and edit a product, add the files and links buyers receive and a cover image, publish it, and check payouts for a connected creator (`/.well-known/mcp.json`). Setup for humans: [Gumroad MCP](https://gumroad.com/mcp) and [connecting AI assistants to your store](https://gumroad.com/help/article/355-connect-ai-assistants-to-gumroad)
- [Help Center](https://gumroad.com/help): documentation for creators and customers

Add Gumroad from ChatGPT’s plugin directory.
- 1. Add the connector Open Gumroad in ChatGPT’s plugin directory and connect it. If you cannot add plugins, ask your workspace administrator. Gumroad in ChatGPT’s plugin directory MCP server URL https://gumroad.com/chatgpt/v1/mcp
- 2. Connect your Gumroad account Sign in to Gumroad when prompted. Review the requested permissions before you authorize access.
- 3. Start a conversation Select the connector in your chat. Try asking, “Show my Gumroad products.”
The connector can access your products, sales, buyer emails, and payouts according to the permissions you grant.
New products start as unpublished drafts. With product access, the connector can publish or unpublish them. Review these actions in your MCP client.
Share your product’s Gumroad link. Customers pay through Gumroad checkout. The MCP server does not take payments in your chat.
Revoke the connection any time in Settings > Applications. Disconnecting the connector in your chat app does not revoke its access token, so revoke it here to end the connection.
