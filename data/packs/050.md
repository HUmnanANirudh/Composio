Commands run against production (https://www.fanbasis.com) by default. The sandbox
is https://api-sandbox.commas.net and needs its own API key, created in the sandbox
dashboard at https://sandbox.commas.net (Account → API Keys). Keys from the old QA
dashboard (qa.dev-fan-basis.com) do not work there. Check and add one with:
commas keys list # which environments have a key
commas keys add sandbox # prompts for the key, no echo
If you ask for sandbox without one, the command stops and tells you — it will never quietly fall back to production.
The server tracks production vs sandbox per MCP session, so the CLI persists your choice locally and re-applies it on every run:
commas env # show current default
commas env sandbox # all future commands run against the sandbox
commas env production
commas tx list --env sandbox # one-off override
If the sandbox switch fails, the command aborts rather than silently running against production.
