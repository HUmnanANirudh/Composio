Getting started
Can you give me an API key?
The Xero API does not support basic API Key authentication. Our API uses OAuth 2.0 which means you need to register your app to get a client id and client secret which you use to access the API.
How can I try out the API?
The quickest way to try out the API is to set up your demo company and dive into the API Explorer. Most of the API functionality is supported and you can quickly start playing with real calls against demo data.
How do I connect Xero to my Salesforce/SQL Database/thing you have no SDK for?
We've got SDKs to cover the most used technologies in the community, but we'll never cater for everyone. If we don't support your particular tech then check out our developer forum archive, or connect with other developers on Stack Overflow. You can also use our OpenAPI spec to generate your own SDK.
How do I get a Xero account to develop/test against?
The first step is to sign up for a free Xero account. Once you have done that, you have two options as to how you can begin development without incurring any cost:
- Use the demo company (recommended)
- Start a trial or paid Xero organisation subscription
Check out our Development Accounts guide for more details.
How do I get support for building my integration?
Hopefully everything you need to know is on the Xero Developer Centre, but if you're still stuck we encourage you to connect with other developers on Stack Overflow, or engage with a Xero certified developer for hire.
What are some best practices for building an integration?
For some of the basics check out our Integration Best Practices guide. After that, browse through the rest of our how-to guides to find more guidance specific to your integration.
What Authentication do you support?
We currently support OAuth 1.0a and OAuth 2.0. However, OAuth 1.0a is in the process of being deprecated and OAuth 2.0 is required for all new integrations.
What kind of App should I build?
That's really up to you! Get connected with accountants and business owners to find out how you can help them be successful.

Remote MCP
Can I connect to more than one organisation?
Yes. A user can authorise several organisations for the same app. Ask the agent to list the connected organisations, then tell it which one to act on. Each organisation still goes through the standard OAuth consent step.
Can I see what my agent did?
Every Xero API call your agent makes is logged in the Developer Portal, under the app you own. Only the API calls are logged, not the tool calls or prompts behind them. If you need a record of what your agent asked for and why, you will need to log that in your own client or agent.
Can I try it before I upgrade?
Yes, apps on Starter plan can use it with the demo organisation. You can connect, run the tools, and decide whether it's worth upgrading to Core. Real customer organisations need the Core plan or above.
Can I use a web app instead of PKCE?
Technically yes. We don't recommend it. A web app's client ID and client secret are easy to paste into an AI-enabled tool by accident, and a PKCE app removes that risk.

The Xero Remote MCP (Model Context Protocol) now generally available
Developers have been using the local Xero MCP server to let Claude, Cursor and other AI tools read and write real Xero data: pull an aged receivables report, draft an invoice, check who still owes you money, all from a chat window.
There was one catch. You had to run it yourself. Download it, configure it, keep it updated and keep it running on your own machine. Fine for one developer experimenting at their desk. Awkward the moment you wanted a colleague, a client or a second organisation to use the same thing.
Today that changes. Remote MCP is now generally available. It’s the same Xero MCP server, hosted and maintained by Xero. Add the URL and sign in. That’s the setup.
What is MCP?
If you’ve heard “MCP” a hundred times this year and still couldn’t define it, here it is: Model Context Protocol is a standard way for AI assistants to use tools. An MCP server is a menu of things an AI can do, with clear instructions for each one. Point an AI assistant at the Xero MCP server and it can list invoices, create contacts or run a profit and loss report, because we’ve described exactly how.
