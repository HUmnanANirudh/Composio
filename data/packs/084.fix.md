[R2] https://402intelligence.paygent.net/llms.txt (official)
# 402intelligence — ecosystem analytics for the agent payment web

Hourly x402 settlement volume and transaction counts across the agent payment web, broken down by
facilitator, protocol, network, and currency. Public and free.

## Explore the dataset (public, free)
- GET  https://discover-api.paygent.net/v1/analytics             dimensional time series (dimension=all|facilitator|protocol|chain|currency, grain=hour|day)
- GET  https://discover-api.paygent.net/v1/stats                 ecosystem totals (services, payments, USDC settled)
- GET  https://discover-api.paygent.net/v1/facilitators/metrics  per-facilitator scoreboard (endpoints, 30d volume/tx, wallet counts)
- GET  https://discover-api.paygent.net/v1/chains/metrics        per-chain scoreboard (30d volume/tx, wallet counts)
- GET  https://discover-api.paygent.net/v1/coverage              directory coverage: payout wallets observed on-chain vs listed in a directory, per chain
- GET  https://discover-api.paygent.net/v1/services              the full service catalog  ·  GET https://discover-api.paygent.net/v1/services/{id}
- GET  https://discover-api.paygent.net/v1/services/{id}/activity  per-endpoint settled payments: totals, daily series, payout wallets (incl. former), payTo change history
- /llms-full.txt                       reputation-ranked dump of the catalog with key fields

## Explorer & intelligence (public, free)
- GET  https://discover-api.paygent.net/v1/tx/{hash}             settlement legs of a transaction, enriched with facilitator + merchant
- GET  https://discover-api.paygent.net/v1/address/{addr}        wallet profile: received/sent totals, daily series, every endpoint paid at it (current + former payTos)
- GET  https://discover-api.paygent.net/v1/operators/{domain}    per-operator profile: endpoints, payout wallets, 30d settled activity
- GET  https://discover-api.paygent.net/v1/wallets/shared        wallets advertised across multiple operator domains (endpoint-farm signature)

## To find and pay a service
Use Paygent Discover: https://discover.paygent.net  (search + per-service detail + payment).

## Notes
- Settlement figures are sampled from on-chain stablecoin transfers attributed to known facilitators
  (x402) or provable MPP markers on Tempo; protocol=mpp counts only marker-bearing payments, while
  protocol=tempo-transfer is bare Tempo transfer traffic.

[R3] https://github.com/usepaygent/paygent-plugin (official)
Payment infrastructure for AI agents. Gives your agent a real, spendable card, funded by crypto — no human needs to type in card details.
From the Cursor Marketplace: search "Paygent", click Add. You'll be prompted for your Paygent API key during install.
From Grok Bot: sidebar account → Settings → Plugins → search "Paygent" → Add.
Manual (mcp.json):
{
 "mcpServers": {
 "paygent": {
 "url": "https://mcp.paygent.tech/sse?api_key=YOUR_PAYGENT_API_KEY"
 }
 }
}
You'll need a Paygent API key. Get one from your dashboard at api.paygent.tech. The key is passed as a URL query parameter (?api_key=...), not an Authorization header — this matches Paygent's existing MCP auth pattern used by Claude Code and other agents.
- create_card — get a crypto deposit address ($1–$2000 in USDG or ETH on Robinhood Chain). A real card is issued automatically once the deposit confirms.
- card_details — full card details (number, CVV, expiry, status, live balance) once ready.
- card_balance — lighter balance-only check.
- Additional tools for closing a card and reviewing deposit/transaction history.
- "Get me a Paygent deposit address so I can fund a card."
- "Check my Paygent card balance."
- "Use my Paygent card to sign up for this API service."
Issues or questions: see the docs at api.paygent.tech/docs.
