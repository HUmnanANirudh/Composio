#### Authentication

1. A user clicks a button in your app to connect to their Pinterest account.
2. Your app redirects the user to our OAuth page. If the user is not logged into Pinterest they will be prompted to do so first.
3. The OAuth page prompts the user to give access to your app with your requested scopes.
4. The user approves access.
5. The user is redirected to your app with an authorization code (passed as a query parameter).
6. Your app calls the OAuth server with the authorization code, requesting an access token.
7. The OAuth server returns an access token.
8. Your app accesses the Pinterest API using the token on behalf of the user.

## Differences between Trial and Standard access

The rate limits applicable for your app depend on the scope the endpoints you use fall under. As a general rule, Standard access offers higher rate limits than Trial access. If you are wanting to use Pinterest features in your production environment, we recommend upgrading to Standard access.

- Your app must already be approved for Trial access and comply with our [Developer Guidelines](https://policy.pinterest.com/developer-guidelines/).
- Prepare a video recording of your app completing an action using the Pinterest API. We will review to verify that you are sending users through the [OAuth flow](https://developers.pinterest.com/docs/getting-started/set-up-authentication-and-authorization/) appropriately and not storing any sensitive information.

- The compliant way for an app to authenticate a user is by obtaining an [OAuth access token](https://developers.pinterest.com/docs/getting-started/set-up-authentication-and-authorization/). If you use other methods, such as collecting user login credentials or Pinterest session cookies, your upgrade request may be denied.
- Demo video does not show live Pinterest integration.

#### Does a Sandbox access token expire?
Yes, Sandbox access tokens are valid for 30 days. After 30 days, the developer will need to generate another one on the My App page.
Does the sandbox environment support all API versions?
No, only the Pinterest API (v5) and onwards will be supported in sandbox
Does this replace the visibility restriction of Pins created in Trial access?
No, Pins created in Trial still behave as Sandbox Pins to a user.
Where can I find the documentation resources for the Sandbox Environment?
Please check more resources in the Developers Portal: https://developers.pinterest.com/docs/dev-tools/sandbox/
SDK
Will the SDK support all API versions?
No, only the Pinterest API v5 will be included in the SDK.
What other languages will be supported in the future?
Node, Javascript, Java.
