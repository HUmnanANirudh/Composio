[S6] https://support.pipedrive.com/en/article/mcp-chatgpt (official)
Pipedrive MCP for ChatGPT
You can connect the Pipedrive MCP server to ChatGPT to allow your AI assistant to securely access and interact with your Pipedrive data.
Before you begin
Make sure that you have permission to install apps in your Pipedrive account and that developer mode is enabled in ChatGPT.
To enable developer mode in ChatGPT, open ”Security and login”. Then, scroll down to ”Developer mode”.
Then, enable ”Developer Mode”.
Create the Pipedrive MCP app
Once developer mode is enabled, go to ”Plugins” on the left-hand side of the screen and click ”+” to create a new plugin.
Enter Pipedrive MCP as the app name and in the ”Connection” field enter https://mcp.pipedrive.ai/mcp. Then, click ”Create”.
After creating the app, you’ll be redirected to Pipedrive to complete the installation.
Install the Pipedrive MCP app
Review the requested permissions in the Pipedrive pop-up. Click ”Allow and install” to complete the installation process.
Once the installation is complete, ChatGPT will be authorized to access your Pipedrive account in accordance with your existing user permissions.
Use Pipedrive MCP in ChatGPT
Before starting your conversation, add the plugin ”Pipedrive MCP” to the conversation.
Your AI assistant can now access Pipedrive data and perform supported actions based on the permissions granted to your account.

Pipedrive MCP for Claude
You can connect the Pipedrive MCP server to Claude to allow your AI assistant to securely access and interact with your Pipedrive data.
Enable the Pipedrive MCP connector
To enable the Pipedrive MCP connector for Claude go to “Customize” and select “Connectors”.
Then, in the search bar, browse for “Pipedrive” and click “Connect”.
Review the requested permissions in the Pipedrive pop-up and click ”Allow and install” to complete the installation process.
Once the installation is complete, Claude will be authorized to access your Pipedrive account in accordance with your existing user permissions.
Use Pipedrive MCP in Claude
Once the connector is enabled, you can start using Pipedrive MCP in your conversations with Claude.
Before starting a conversation, open a new chat and verify that Pipedrive is enabled and available.
Your AI assistant can now securely access Pipedrive data and perform supported actions based on the permissions granted to your account.
Note: By default, Claude may not load all available MCP tools when starting a conversation. If you need access to all Pipedrive MCP tools, enable the setting that loads all available tools in the connector configuration.
